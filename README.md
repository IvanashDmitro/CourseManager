# Система управління навчальними курсами (CourseManager)

Курсова робота з дисципліни «Об'єктно-орієнтоване програмування».
Виконавець: Іванаш Дмитро Іванович, група 3РП-11, ВСП «ОТФК ОНТУ».

## Стек технологій
- C# / .NET 10
- Avalonia UI 12 + CommunityToolkit.Mvvm (шаблон MVVM)
- System.Text.Json (поліморфна серіалізація `CourseActivity`)
- XmlSerializer (експорт відомості курсу в UTF-8)
- Serilog (логування подій і помилок у `app.log`)

## Запуск
```bash
dotnet restore
dotnet build
dotnet run
```

## Основні правила
- Новий курс отримує стандартний набір робіт на 100 балів (4 лабораторні по 15, 2 практичні по 10, 2 тести по 10). У блоці «Роботи курсу» роботи можна додавати, змінювати й видаляти: тип, назва, максимальний бал, дедлайн і параметр типу (бонус за захист, штраф за запізнення в %, кількість питань).
- Рейтинг – набрані бали у відсотках від суми максимумів робіт курсу (шкала 0–100), поруч показано оцінку за національною шкалою.
- Здобувач може навчатися на кількох курсах (кожен запис – окремий рядок таблиці); заборонено лише повторний запис на той самий курс.
- При першому запуску генерується 100 здобувачів (частина з них на двох курсах); частина робіт ще не здана, тому в таблиці видно наступну роботу і її дедлайн. Кнопка «15 000 оцінок» (після підтвердження) створює великий набір для замірів T1/Tn, кнопка «Стартовий набір» повертає 100 здобувачів.
- Щоб виставити оцінку: клацнути рядок у таблиці → обрати роботу у списку (одразу пропонується наступна невиконана) → ввести бал → «Виставити оцінку».
- Щоб змінити ПІБ, групу чи назву курсу: клацнути рядок у таблиці (поля праворуч заповняться) → виправити текст → «Оновити».
- Поле шляху використовується і для «Імпорт JSON», і для «Експорт JSON» (наприклад, `backup.json`). Після імпорту чи генерації дані зберігаються в `courses.json`.
- Щоб змінити роботи курсу: обрати курс у «Керуванні курсами» → у «Роботах курсу» обрати роботу (поля заповняться) → змінити → «Оновити»; для нової роботи – заповнити поля і «Додати».
- Перед видаленням курсу, роботи, здобувача чи запису, перед імпортом і генерацією застосунок просить підтвердження.
- «Рейтинг T1/Tn + XML» рахує рейтинги в одному і в кількох потоках (з прогрівом, найкращий із трьох замірів) і записує відомість `course_grade_sheet.xml`, згруповану за курсами.
- Якщо після оновлення програми щось виглядає дивно (старі групи, старі імена), натисніть «Стартовий набір» або видаліть `courses.json` поруч із програмою.

## Тека `data/` для тестування обробки винятків
- `data/broken_syntax.json` – обірваний JSON (перевірка `JsonException` → `IOException`);
- `data/invalid_score.json` – бал 150 при максимумі 20 (перевірка `ArgumentOutOfRangeException`);
- `data/duplicate_enrollment.json` – повторний запис одного здобувача на той самий курс (перевірка `InvalidOperationException`).
